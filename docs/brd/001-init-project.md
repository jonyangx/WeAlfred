构建一个mac os app 应用，复刻Alfred软件，只需要一部分能力，就是快捷键方式打开app，打开文件，进入目录。
也可以参考raycast 类似的。
自签名，没有苹果开发者账号。仅仅自己使用。

## 首版需求澄清

- WeAlfred 是面向个人使用的 macOS 14 及以上菜单栏应用。启动后即可搜索。默认用 `⌥ Space` 显示或关闭面板，注册失败时尝试 `⌃⌥ Space`，菜单栏入口始终可用。
- 从搜索框输入应用、文件或目录名称。按名称匹配，支持中文以及忽略大小写的部分名称匹配。可以按类型筛选。默认选中第一条结果，可用 `↑`、`↓` 切换，按 `Return` 打开，或用 `Esc` 关闭面板。也可以点击结果打开。
- 打开应用时启动或切换到对应应用。文件交给 macOS 默认关联程序，目录在 Finder 中打开。打开失败时，面板保留并提示错误。
- 默认搜索系统和当前用户的常用应用目录、用户主目录的第一层，以及 `~/Desktop`、`~/Documents`、`~/Downloads` 的子目录。可从菜单栏增减自定义搜索目录，按名称搜索使用本地文件系统索引。粘贴完整的绝对路径或 `~/` 路径可直接打开项目，包括索引范围外的项目。
- 提供编译、签名打包和测试脚本。打包生成 `.app` 和 `.zip`，默认使用 ad hoc 签名，也支持使用本机钥匙串中的自签名证书。构建流程无需 Apple Developer 账号。

## 验收

1. 打开打包后的应用，切换到另一个应用，用全局快捷键唤出面板并直接输入文字。
2. 按名称找到并打开计算器，搜索测试文件并用默认程序打开，搜索测试目录并在 Finder 打开。
3. 添加一个额外搜索目录，确认其中的文件可按名称查找。移除该目录后，仍可粘贴文件完整路径打开。
4. 用方向键切换搜索结果并按回车打开。粘贴有效的完整路径并立即按回车，确认查询完成后会打开目标。按 `Esc` 关闭面板，确认失效路径有提示。
5. 运行 `./scripts/test.sh`，验证自动测试、应用签名和 ZIP 解压完整性。
